# Raffle Winner Picker Documentation

## Overview

The Raffle Winner Picker is a desktop application used to randomly select raffle winners from Excel-based entrant lists.

This repository contains public documentation, screenshots, and workflow information for the application.

The application source code is maintained separately in a private repository.

---

## Features

- Random winner selection
- Excel spreadsheet import
- Multiple raffle support
- Configurable number of winners
- Winner reporting and output
- Repeatable drawing process

---

## Basic Workflow

1. Prepare raffle entry spreadsheet
2. Launch the application
3. Select the raffle file
4. Specify the number of winners
5. Run the drawing
6. Review and record the results
